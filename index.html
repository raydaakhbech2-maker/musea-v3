Explorer le web

Navigateur

Important : cette version propose un prototype de navigation web. Ce n'est pas un navigateur complet comme Chrome ou Opera GX. Les sites seront ouverts dans le navigateur de ton appareil ; une vraie intégration nécessite une application native utilisant Android WebView et iOS WKWebView.

Favoris

Pour des raisons de sécurité et de compatibilité, les pages ne sont pas intégrées dans une iframe : beaucoup de sites bloquent ce fonctionnement. Le bouton ouvre la page dans un nouvel onglet.

Pour une version native complète

On pourra construire un écran navigateur avec onglets, favoris, historique, navigation arrière/avant, gestion des permissions et filtres de sécurité. Le moteur sera celui fourni par le système, pas un moteur Chromium complet indépendant.
