Explorer le web

Navigateur

Important : cette version propose un prototype de navigation web. Ce n'est pas un navigateur complet comme Chrome ou Opera GX. Les sites seront ouverts dans le navigateur de ton appareil ; une vraie intégration nécessite une application native utilisant Android WebView et iOS WKWebView.

Favoris

Pour des raisons de sécurité et de compatibilité, les pages ne sont pas intégrées dans une iframe : beaucoup de sites bloquent ce fonctionnement. Le bouton ouvre la page dans un nouvel onglet.

Pour une version native complète

On pourra construire un écran navigateur avec onglets, favoris, historique, navigation arrière/avant, gestion des permissions et filtres de sécurité. Le moteur sera celui fourni par le système, pas un moteur Chromium complet indépendant.

MUSEA / MAÎTRISE DE MES DONNÉES

Mon dossier MUSEA

Récupère une copie lisible des informations associées à ton compte : profil, créations, interactions, collections, notifications, projets privés et éléments de collaboration auxquels tu as accès. L'export interroge uniquement les données autorisées par ta session et les règles RLS.

Aucun export lancé.

Les images ne sont pas copiées dans le fichier : leurs références et chemins disponibles sont conservés. Les messages exportés sont uniquement ceux que tu as envoyés, pas les messages privés des autres membres. Si une migration manque, le fichier signale les catégories indisponibles au lieu de les inventer.

Suppression du compte

La suppression définitive n'est pas activée depuis cette interface : elle doit aussi traiter les fichiers stockés, les abonnements éventuels, les données liées et les sessions côté serveur. Aucun bouton ne prétend supprimer ton compte tant que ce parcours sécurisé n'est pas déployé.
